## 2. 目录职责说明

### `src/agents/`

每个 Agent 子目录对应一个专业角色，内部遵循统一接口：

```python
class BaseAgent:
    async def collect(self, input_data) -> OutputData:
        """同步执行"""
        pass

    async def acollect(self, input_data) -> OutputData:
        """异步执行（推荐）"""
        pass

    async def stream(self, input_data):
        """流式输出（用于 WebSocket 实时推送）"""
        yield "step_1_result"
        yield "step_2_result"
```

### `src/core/`

系统核心组件，提供跨 Agent 的共享能力：

```
config.py      — 统一配置（同时支持 .env 和 YAML）
llm_client.py  — LLM 调用抽象（支持 Claude/GPT-4/通义千问自动切换）
workflow.py    — 工作流编排（基于 LangChain LCEL）
vector_store.py — 向量相似度检索（pgvector）
scheduler.py   — 定时任务（Celery Beat）
cache.py       — Redis 缓存
logger.py      — 结构化日志（JSON 格式）
```

### `src/api/routers/`

每个路由文件对应一组相关功能，路由内部不写业务逻辑，只做参数校验和响应格式化。

## 3. 文件命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Python 模块 | `snake_case.py` | `article_writer.py` |
| 配置文件 | `kebab-case.yaml` | `settings.yaml` |
| 文档 | `MM-描述.md` | `03-功能规格.md` |
| 脚本 | `snake_case.py` | `daily_collect.py` |
| 测试 | `test_xxx.py` | `test_article_writer.py` |
| Prompt 模板 | `kebab-case.md` | `writer.md` |

```python
# 绝对导入（推荐）
from src.agents.collector import RSSFetcher
```
